# 🔍 读心解码（`duxin-jiema`）· 聊天记录与双视角识人全书

> 📌 **本 skills 来自抖音/小红书：琉璃梦碎落 & 舔魂宗｜免费开源｜定制化可联系社媒**

一个开源、独立、包罗万象的 **AI 聊天记录逐句解码与双视角识人决策技能（Skill）**。整合男向撩妹库、女向撩汉库 407 本原书框架与 169 篇真实案例，专治“看不透对方这句话什么意思、分不清真心还是玩玩、冲动发错消息把好牌打烂”。

---

## 一、核心亮点

1. **强制时间轴校验**：第零步强制执行 `Get-Date`，杜绝 AI 凭记忆或截图误判“几天没回”。
2. **先接情绪，再讲证据**：先安抚防冲动，再把聊天记录拆成**实锤堆 / 推测堆 / 未知堆**，彻底剔除主观脑补。
3. **双视角硬隔离**：支持男向与女向双视角，清晰识别长择/短择 7 维度、剪刀石头布、免责声明、婚前杀价、废物测试、故事试探、PUA 打压与感情仙人掌。
4. **四分支可执行下一步**：不止给一句自然人话回复，还给发送时机、**对方积极 / 含糊 / 冷淡 / 拒绝**四分支预案及明确观察窗口。
5. **本地隐私档案记忆（可选）**：内置零依赖 Python 脚本 `scripts/memory_store.py`，仅在用户明确授权后本地保存匿名关系档案与时间轴。

## 三、快速开始

1. 将整个 `duxin-jiema/` 文件夹放入你的项目或工具技能目录（如 `.agents/skills/`、`.claude/skills/`、`.codex/skills/`）。
2. 直接贴出聊天记录或描述困境，例如：
   - `用读心解码逐句分析这段聊天记录，判断他是真心推进还是敷衍抽离，给我下一步回复和分支预案。`
   - `她刚才说“我脾气其实挺差的，追我的人也多”，帮我拆解是不是废物测试，给三个不同温度的回法。`
