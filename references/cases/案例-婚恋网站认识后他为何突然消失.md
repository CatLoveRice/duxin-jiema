# 婚恋网站认识后他为何突然消失——伪钞战术的识别

## 来信摘要
27岁女，在婚恋网站认识32岁港男。对方条件不错，他见面后经常临时约她，问她的感情经历（包括性经历细节）。她说不接受婚前同居，对方态度骤冷直至消失。她困惑：是她太保守还是对方太自卑？

## 专家分析
### 底层逻辑
- 这个男性的策略叫"伪钞战术"：用看起来很有吸引力的条件（条件好）作为"兜里的伪钞"，让女性以为捡到便宜
- 他一开始就释放性暗示、临时邀约、打探情史——这是泡妞的惯用套路
- 她拒绝婚前同居后他消失——说明他接近她就是为了性

### 策略要点
1. 他不是只撩拨她一个人——他有大量时间分散在不同"猎物"上
2. 男人对真心喜欢的女人不会那么在意"自尊"
3. 求婚时男人膝下有黄金也要跪——这点自尊算什么？
4. 条件好的男人更容易用"条件"迷惑人，让人忽略他的真实目的
