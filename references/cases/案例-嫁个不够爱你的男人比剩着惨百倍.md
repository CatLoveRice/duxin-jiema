# "怀了孩子就打了"——嫁个不够爱你的男人比剩着惨百倍

## 来信摘要
25岁女，毕业后谈过一次恋爱后五个月前认识现任北方男友。感情尚可，他有点大男子主义但愿意为她改变。她试探性地问他关于"意外怀孕后马上结婚生下来"的看法，对方坚决否定，说"经济工作不稳定，必要的时候需要牺牲一下（打胎）"。她感到心寒：他是否太自私？是否该继续？

## 专家分析
### 底层逻辑
- 他诚实不等于他是好人——他摆明了利害关系，把责任皮球踢给了她
- 避孕套1-2%的失败概率——两年内怀孕一两次是绝对可能的
- 他想要享受没有义务的性爱——"不能给孩子好的教育环境"只是冠冕堂皇的借口
- 如果他很爱她，会巴不得赶快生个孩子把她套牢——他根本不打算和她长久

### 策略要点
1. 打胎的风险远大于失去任何一个男人的风险
2. 要么让他结扎——如果他愿意为自己"负责任"
3. 要么坚决不和他发生关系——直到他准备好承担
4. 当剩女至少还是未婚女，嫁个不够爱你的男人万一分手更难

## 关键金句
"当剩女固然不是什么好事，可是嫁个不够爱你的男人比当剩女惨一百倍。'剩'着至少你还是未婚女，没准儿哪天就嫁给了好人家。嫁给不够爱你的男人，万一离异，你可就比较难以再嫁了。"
