# 拒绝给你未来的男人，你还有多少青春可以浪费

## 来信摘要
22岁女，与条件优渥的男友恋爱两年。男友父母不同意两人关系（她是外地人、家境一般），男友抗争无效后不提及此事。明确说"没有结婚的可能"。女方提分手后又忍不住和好。现在男友家正在办出国手续，他妈说"如果你能一起出国就同意你们"——实质是看他家有没有这个钱。男方还不想要孩子。她不知该不该等。

## 专家分析
### 底层逻辑
- 在得到性满足之前，智人男性都会表现出对婚姻的向往——婚姻是男人能给予女人的最大礼物
- 如果男人明示不给你婚姻和未来，你继续跟着他，比被包养更糟
- 包养至少还拿到钱，你这是在"把青春折算成嫖小白脸的费用"
- 世界上没有不想要孩子的男人——只有"还没到想要孩子的年龄"或"不想和你生"

### 策略要点
1. 他说"等工作以后"——不过是驴子眼前的稻草，永远吃不到
2. 痴情这件事好像手淫，自己觉得爽，别人看来恶心
3. 现在你22岁是最好的花季，不要把青春拿来嫖小白脸
4. "不想要孩子"=注意避孕，怀孕了自己去打掉

## 我的代入思考
这个案例中男方明确告知"没有未来"，已经是非常清晰的信号了。Ayawawa的"嫖小白脸"比喻虽然刻薄但直击要害：女性付出青春和感情，男性享受无负担的性关系——这比被包养还廉价，因为包养至少在经济上有所补偿。关于"不想要孩子"的解读也很精准：他不是不想要任何孩子，只是不想要和她的孩子。
