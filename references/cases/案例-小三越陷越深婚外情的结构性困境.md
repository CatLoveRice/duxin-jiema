# 所有的小三都是被骗上床后越陷越深的

## 来信摘要
南方漂亮女孩，硕士毕业时经老乡帮忙解决北京户口和好工作。老乡（大15岁，有家室）以锻炼为名约她，一年多后表白。她逃避三个月后，在脆弱时接受。他说"非你不娶"、过无性婚姻。关系被老婆发现后，他说等孩子送出国再处理。她怀孕后流产，仍离不开他。他老婆会欲擒故纵的手段，她只会跟他吵架。她不工作靠他养，挣扎着不知该不该离开。

## 专家分析
### 底层逻辑
- 他既不想放弃老婆（孩子、社会形象、家族资源）也不想放弃她——这是最自私的状态
- 她以为"他们不相爱"——但他不离婚一定有他的理由，不离婚的行为比任何承诺都真实
- 一个人在北京需要依靠可以理解，但这个"依靠"的代价太高
- 他不是不能离婚，是不想离婚——不想付出成本

### 策略要点
1. 他说等孩子出国就处理——这是缓兵之计，孩子出国有可能，但"处理"遥遥无期
2. 不工作靠他养会形成"路径依赖"——越久越难离开
3. 如果他真的爱你到要离婚的程度，他早就离了
4. 不要把自己的未来寄托在别人的"承诺"上
