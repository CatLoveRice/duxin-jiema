# 被极品烂男伤害后：从自我否定到价值重建

## 来信摘要
女性的前男友在恋爱期间偷偷相亲，在大家以为要订婚时告诉她"爱上了别的女孩"。真相更可怕：他道德败坏、谎话连篇、自私，还吸过毒、嫖过娼。分手三个月后她仍反复纠结，不是留恋他，而是不能接纳自己——"是他不值得爱，还是我不值得爱？"她极度自卑，问Ayawawa如何重建自我价值感。

## 专家分析
### 底层逻辑
- 每个极品烂人曾经都拥有无邪笑容——这不代表他现在的烂与你有关
- 你是一个受害者，不能说明你有什么问题，只能说明你还没见识世间险恶
- 她真正的痛苦不是失去他，而是"我为什么会爱上这种人"——这是自我认知的碎裂

### 策略要点
1. 不是"他不值得爱"也不是"我不值得爱"，而是在爱中还没有学会保护好自己
2. 自我价值的重建需要时间，但第一步是停止自责
3. 接纳"自己也会被欺骗"这个事实——这不是你的错
4. 如果恨，就恨自己不够坚强——然后学着坚强起来

## 关键金句
"在这件事情里，你是一个受害者啊。这不能说明什么，只能说明你是个还没有见识世间险恶的一个善良的人。谁没有被骗过的时候呢？"
