# "忙正事"——是真忙还是变心的挡箭牌

## 来信摘要
女大学生与同校男友交往半年。男友在帮家里管理市场方面的事务，生活大半时间花在"正事"上。答应的事经常变卦，每次来找她甜蜜一会儿就找借口走。他忙的时候不主动联系她，她发信息很少回复。她说未来"说不定"。她在一线城市无收入靠他帮忙，周末做兼职。问他，答"事业比较重要"。

## 专家分析
### 底层逻辑
- 科学研究：喜欢说谎的男人容易出轨——出轨和说谎常并存于同一人身上
- 问一个男人是否出轨没用——他肯定会骗你
- 商品的价值来源于稀缺性——当她太需要他时，他就不那么需要她了
- 她所谓的甜蜜和相拥，在他看来可能只是排遣身体需要

### 策略要点
1. 不要爱上你的"字典情人"（Sleeping Dictionary）——把他作为适应这座城市的工具
2. 世界上哪有十全十美——能帮你解决经济困难又爱你入骨的男人？
3. 很多人都以为自己是主角——其实不过是在跑龙套
4. 努力早日成长为一个独立的人

## 关键金句
"很多人以为自己就是主角，没事就把自己往电视电影故事里套，不过套了半天才发现自己不过是在跑龙套。"

## 我的代入思考
这个案例中女性处于严重的"权力不对等"状态——经济上依赖、情感上渴望、信息上不对称。Ayawawa用《字典情人》的比喻非常贴切：她把男友当恋人，男友把她当"临时伴侣"。核心教训就是"经济独立→情感独立→关系平等"。
