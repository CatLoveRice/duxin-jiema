# 强势妻子遭遇丈夫再度暧昧——是选择原谅还是果断离开

## 来信摘要
结婚十年的夫妻，她是强势的一方，生意决策多由她敲定。两次发现丈夫与别的女人发暧昧短信。第一次他哭着保证，时隔不到两年又犯。她觉得自己已经失去了信任他的能力，不想变成"翻老公聊天记录的女人"。但离婚涉及孩子、生意、双方父母，十二年感情难以割舍。

## 专家分析
### 底层逻辑
- 两个人在一起之后的基础，有时是"分开的损失大于在一起的损失"——就像器官移植后出现了排异，服用抗排异药物总比重新移植代价小
- 她生气不是因为他，而是因为自己——恨自己需要这个人，恨他没她想象的那么爱自己
- 离婚是伤人一千自损八百的做法

### 策略要点
1. 与其冲冠一怒，不如借此收回经济大权——用金钱的匮乏阉割他的欲望
2. 将他看做一个"不爱的罪人和生活伙伴"——至少现在在一起的收益大于分开
3. 让他去做全面身体检查——在结果出来前不和他发生关系
4. 试着放下对他的期望和要求——日子已经给你添堵，别给自己添堵

## 关键金句
"你之所以生气，不是因为他，而是因为你自己。你恨自己竟然这么需要这个人，你恨他竟然没有那么爱你尊重你，所以你才迫不及待地想离开这段让人感到憋屈的关系。"
