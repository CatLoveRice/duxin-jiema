# 案例：背后的数字——一场揭示婚恋匹配真相的实验

## 案例摘要
> 实验人员找来100位大学生（男女各半），制作1-100的卡片贴在每个人背后——单数给男生，双数给女生，每人不知道自己数字。要求自由配对，使两人数字总和最大。结果：大多数人都在向数值大的人献殷勤；数值大的人变得挑剔；数值小的人无论如何努力也很难得到青睐；最终大部分配对的男女都是数字相近的。分数相差超过20的伴侣非常少。
>
> 实验还发现：围着数字大的人最多的人一定是数值更大的；通过"谁身边围着的人多"可以快速判断谁是高价值者。

- **当事人**：100位大学生
- **关系阶段**：模拟择偶配对
- **核心冲突**：价值不对等的追求 × 价值匹配的现实
- **关键行为**：低数字努力追求高数字但很难成功；最终匹配的都是数值相近的
- **结局**：精确的价值匹配

## 理论分析

### 底层逻辑
这个经典实验揭示了**婚恋市场的本质是一场精确的价值匹配游戏**。所谓的"爱情"，背后是MV的匹配和博弈。

几个关键发现：
1. **吸引力等于被多少人追求**——你被多少人追，就大致反映了你的MV
2. **门当户对不是偏见，是规律**——MV相差超过20的单位几乎无法配对
3. **越受欢迎的人越挑剔**——这产生了马太效应：你越受欢迎就越受欢迎
4. **低价值追高价值要付出不成比例的努力**——而且大概率仍然会失败
5. **欺骗可以阶段性有效**——有些人会虚报价值来获取短期优势，但长期会被揭穿

**"一个人有多优秀，他自己一定是知道的"**——书中多次强调，高MV的男性和女性都知道自己的价值，不要幻想自己可以"捡漏"。

### 策略要点
1. **认清自己的"数字"是择偶第一步**——高估会剩下，低估会下嫁
2. **"谁身边围的人多"是一个快速判断MV的方法**
3. **不要奢望偶然一次"奋力一跃"成为常态**——那是不可持续的
4. **匹配之外的关系一定有隐性代价**——要么你付出更多，要么对方有不可见的问题
5. **交际圈和环境会极大影响择偶结果**——不在"好池子"里，你的好可能不会被看到

## 我的代入思考
这个实验是我最喜欢的婚恋心理学实验之一——因为它用一个极简的模型揭示了复杂婚恋市场的核心规律。100个大学生、100个数字、简单的配对规则，但结果和现实社会的婚配几乎一模一样。

最让我触动的是实验中"低数字者"的挣扎——他们付出了巨大的努力（甚至用承诺、欺骗手段），但结果仍然是和相近数字的人在一起。这解释了为什么很多人在感情中"已经很努力了"却没有好结果——**因为问题不是出在"不够努力"，而是出在"数字不对"**。

另外，"谁身边围着的人多，谁的数字大"这个规律很有实操价值——在社交场合中，观察一个人被关注的程度即可大致判断其MV。这比看硬件条件（收入、学历、家庭）更准确，因为人气本身就是综合MV的外在表现。
