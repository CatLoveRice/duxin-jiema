# 案例-五年追求的仙人掌·他追到后为何心态扭曲

## 来信摘要

一个男生追求校花（毕业后做空姐）追了5年。这5年中，女生一直明确拒绝他，但男生坚持不懈，始终对她很好。后来男生偶然小赚一笔，买了车子和房子。他把这些物质条件摆在女生面前，慎重向她求爱。

女孩犹豫后给了一个真诚的回应："我知道你现在也不清楚自己对我到底是征服欲还是真心。没关系，我给你机会——如果我们在一起后你觉得对我只是征服欲作祟，我放你离开；倘若你是真心，我就决不放手。"

男生却因此跑到论坛上发帖问：**"因为钱，拒绝我5年的女生现在开始倒追我，怎么办？"**

## 专家分析

### 底层逻辑

这个案例的核心问题出在男方在爱情中受挫太多，即使富有了也始终不具备自信，甚至比女方更没有安全感。他对爱情的态度是一种**暴发户心态**——他惧怕失去，对感情的到来有深刻的不确定和无力感。

文中将其比喻为**"感情仙人掌"**：
- 仙人掌适合生存在感情荒漠里
- 如给它过多水分，它反而会淹死
- 他现在得到了很多水分，却开始怀疑"她是不是因为钱才接受我"

### 策略要点

1. **嫌货人才是买货人**：他之所以怀疑女生的动机，是因为他自己就是用物质来"买"这段关系的。他把自己的车房当作砝码，自然认为对方也是冲着砝码来的。

2. **钱是择偶的加权值，不是决定因素**：把钱的作无限夸大或缩小的人，认知能力都有偏差。一个空姐去哪里找不到有车有房的男人？她是真的被打动了，才愿意委屈自己接受一个扭曲心态的男人。

3. **不要找一直对你奴颜婢膝的男人**：爱情与同情不能兼容。如果爱情的基石只是感动而非理性评估，一定不长久。"坚持得久了，就会忘记自己在坚持什么"——这样的男人得到后反而会迷茫。

4. **不能因为曾经穷，就要求对方撇开钱的因素爱你**：这既不现实也不公平。男性选择配偶时挑基因优质，女人选择丈夫时挑有安全感——这是进化本能，无法逆规则而行。

## 关键金句

- "感情仙人掌适合一辈子生存在感情荒漠里，如给它过多的水分，它反而会淹死。"
- "把一切归功于钱，而不是自身的魅力——这说明他是一个没自信、没魄力、没胆识的男人。"
- "千万不要找那种对你一直奴颜婢膝、什么事情都愿意做、追你很长时间的人。爱情与同情不能兼容。"
- "坚持得久了，就会忘记自己在坚持什么——将这句话套用在爱情里，同样适用。"
