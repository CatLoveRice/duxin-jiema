# 02 · 潜台词与免责条款翻译大全

## 一、免责声明（“盗版软件”条款）翻译表

像安装盗版软件前弹出的免责勾选框——对方提前把话说在前面，一旦你默许继续，后续所有的不负责他都觉得理所当然：

| 对方原话 | 真实潜台词 | 危险等级 |
|---|---|---|
| “我不想耽误你的青春” | 我不打算给你未来，但想继续享受当下，提前撇清责任 | 高危 |
| “我受过情伤，已经丧失爱人的能力了” | 我可以和你在一起，但别指望我好好对你和负责 | 高危 |
| “现在的我还不够好，配不上你” | 提前找好体面退场的台阶，把分手锅甩给“客观条件” | 高危 |
| “先处着看看吧，顺其自然” | 拒绝承诺绑定，走一步看一步，你别催我 | 中高 |
| “婚姻不过是一张纸，何必在意形式” | 我不想结婚，或不想和你结婚 | 高危 |
| “你如果遇到更适合的人，我祝福你” | 我已不再为你投入排他成本，心理上已准备抽离 | 高危 |
| “我最近事业为重 / 状态不好” | 事业和爱情从来不是二选一，只是你在我优先级里不够高 | 中高 |
| “反正你这么懂事/三点一线很省心” | 你已经没有稀缺感和离开威胁，我可以放心降低维护成本 | 中高 |

## 二、常见试探与推诿话术解码

| 场景类型 | 典型原话 | 真实意图 | 正确应对方向 |
|---|---|---|---|
| **废物测试（女测男）** | “追我的人很多”“你对每个女生都这么说吧”“你是不是挺会撩” | 测你内核稳不稳、会不会急眼自证或卑微讨好 | 严禁认真解释或发火；用幽默自嘲、夸张同意或平静立界后切话题 |
| **嘴贱打压/杀价** | “细看倒还行”“最近是不是胖了”“买这东西谁送的？” | 压低你的自我评价以掌握高位、试探你的底线 | 绝不接框架自证；平静反弹或即时收回情绪供给 |
| **故事试探** | “我哥们越界了他太太很大度原谅了”“圈子里应酬多难免” | 借第三方故事探测你的底线刻度 | 绝不顺着温和附和；当场亮明零容忍态度 |
| **拒绝公开** | “你太好看了我怕炫耀/我习惯低调不发朋友圈” | 在社交池里保留单身展示面 | 不听漂亮话，看是否带你进真实熟人/朋友核心圈 |
| **越界玩笑** | 和异性/你闺蜜开暧昧玩笑后说“逗着玩的你怎么这么较真” | 模糊边界、把越界包装成你小心眼 | 不必自证大度，平静直说“这个尺度我不接受”，看后续行动 |
| **伪大方清库存** | 拿冲额度剩的冷门配货/无小票闲置当大礼，强调“特意挑的” | 零成本清闲置顺带赚大方名声 | 嘴软心硬，心里直接重估对方的诚意与投入度 |
