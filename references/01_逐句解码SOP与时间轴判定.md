# 01 · 逐句解码 SOP 与时间轴判定

## 一、底层解码铁律（双库共通）
1. **潜沟通压倒字面（一九定律）**：80%–90% 信息藏在语气、回复节奏、主动比例与实际行动中；嘴和行动冲突时，100% 信行动。
2. **情绪先于逻辑**：先看对方此刻的情绪状态（防御 / 试探 / 敷衍 / 愧疚 / 索取 / 渴望），再看字面逻辑。
3. **沉默与拖延就是答案**：长期不推进、用“忙/状态不好/以后再说”搪塞 = 当前优先级不够高。
4. **朋友圈不是对你说话的地方**：严禁把对方公开发在社交圈的文案脑补成“暗示我”。

## 二、聊天记录逐句解码四步法
1. **拉时间轴**：先核对 `Get-Date` 与聊天时间差——算清谁先发起对话、平均回复间隔、冷淡已持续几天、承诺过的事过没过期。
2. **分堆过滤脑补**：
   - **实锤堆**：原话、精确时间、已落地的行为（见没见面、买没买单、守没守约）；
   - **推测堆**：求助者自己脑补的动机（“他可能只是害羞/最近压力大”）；
   - 铁律：一切定性只基于实锤堆。
3. **逐句三层解码**：
   - **表层字面**：TA 说了什么；
   - **真实潜台词**：TA 真正想传递的态度或试探什么；
   - **权力与投入流向**：这句话是在拉近距离、推卸责任、索取情绪，还是测试你的底线。
4. **输出多温度回应**：绝不给油腻土味或强操控话术；给出“不回/延后回”或“克制冷静 / 轻松幽默 / 明确立界”三种自然人话方案。

## 三、冷淡与敷衍分级标准
- **正常短期冷淡（1–3 天）**：有明确客观事由（出差、生病、家事），结束后主动说明并补回互动质量 → 保持稳态，不追问不翻脸。
- **预警冷淡（4–7 天）**：回复字数骤减（长句变“嗯/哦/哈哈”）、只答不问、话题终结 → **立即减供给、停止主动加码**，观察对方是否主动补位。
- **抽离/慢待信号（>7 天或连续 3 次敷衍）**：反复临时取消约会不补约、对你的细节挑刺逼你道歉 → 停止发小作文质问，直接用一次轻量化明确动作（或直接止损）拿结果。
