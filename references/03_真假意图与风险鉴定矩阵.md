# 03 · 真假意图与风险鉴定矩阵

## 一、长择（真心）vs 短择（玩玩）7 大维度鉴定表

单条信号不下定论，综合对照行动（行动 > 嘴上承诺）：

| 维度 | 长择信号（认真考虑你） | 短择信号（低成本套利） |
|---|---|---|
| **1. 公开程度** | 主动带你进朋友/家人/同事圈，不藏着掖着 | 隐秘交往、对外宣称单身、公共场合刻意拉距 |
| **2. 时间与规划** | 提前规划约会、守时稳定、持续投入 | 永远当天临时邀约、画大饼不落地、被拒就冷淡 |
| **3. 未来叙事** | 谈起几年后生活自然包含你 | 只谈当下，聊到未来规划就沉默或转移话题 |
| **4. 情绪与冲突** | 在意你的感受、吵架后主动修复 | 表面无限容忍（因为不打算长久）或遇矛盾直接冷处理消失 |
| **5. 后撤测试反应** | 你放慢节奏或表达不安时，会反思并稳住诚意 | 发现成本变高“不划算”，立刻冷淡转移目标 |
| **6. 对前任态度** | 客观评价前任、承认自身问题（高专情信号） | 全怪前任、卖惨“被辜负/爱无能” |
| **7. 边界尊重** | 尊重亲密节奏、愿意等待 | 急于突破身体边界、软磨硬泡试探 |

## 二、男性择偶三模式速判：「剪刀 · 石头 · 布」
- **石头（普通供养者）**：稳定、按部就班、看重专一确定性；风险是乏味或控制欲强。
- **布（高阶资源者）**：实力、眼界、气场占优，能托底；风险是身边选项多、情绪分配不均。
- **剪子（高魅力情人）**：颜值/谈吐/情绪价值极强，最易让人上头；风险是往往回避长期承诺、投入精明。

## 三、初识与日常真假兴趣信号（IOI）
- **有效信号（主动性与连续性）**：主动发起话题、记住你们的梗并延用、主动分享日常细节、愿意为你调整时间、拆礼物先体验再认真反馈。
- **无效信号（礼貌与错觉）**：职业微笑、客套回“哈哈/嗯嗯”、偶发朋友圈点赞、拉你当情绪垃圾桶或带你和别人一起玩（安全朋友区）。
- **初识三回应**：防备追问（“有什么事？”）→ 撤退；逻辑追问（“为什么找我？”）→ 真诚给理由；情绪回应（“吓我一跳”）→ 窗口开放。

## 四、五大高危人格/套路预警
1. **完美套路与巴南效应**：刚认识就喊亲密称呼、画大饼规划未来、用万能模糊赞美制造“灵魂伴侣”错觉——真正动心往往带有一点克制的笨拙，而非滴水不漏的剧本。
2. **PUA 打压男（哈哈镜效应）**：一边自我膨胀、一边通过微贬低让你不断自证“我值得被爱”，越照越自卑。
3. **感情仙人掌**：长期低位苦追多年得到后心态扭曲，怀疑你是看中物质条件，用“当初你看不上我”反复折磨关系。
4. **弥补性恋人**：刚经历情伤无缝衔接，拿你的偏爱当止痛创可贴，却总在不经意间提旧人。
5. **软刀子被动伤害**：不吵架也不作为、不公开不维护，用长期慢待倒逼你先提结束。
